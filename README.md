# Mayank Upadhyay — Portfolio

Personal portfolio website built with React + Vite + Framer Motion.

## Tech Stack
- React 18
- React Router v6
- Framer Motion
- Vite 5

## Local Development

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173` in your browser automatically.

## Deploy on Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import your GitHub repo
4. Leave all settings as default (Vercel auto-detects Vite)
5. Click **Deploy** ✅

Routing is handled by `vercel.json` — no extra config needed.

## Build for Production

```bash
npm run build
npm run preview
```
